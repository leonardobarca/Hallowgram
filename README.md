# Hallowgram 🐛

Um clone do Instagram inspirado no universo de Hollow Knight, construído do zero com React.

## 🎮 Sobre o projeto

O Hallowgram é um projeto de estudo onde recrio as funcionalidades principais do Instagram com uma temática do jogo Hollow Knight. O objetivo foi aprender React na prática construindo algo real.

## ✨ Funcionalidades

- Feed de posts com scroll
- Botão de like funcional (com contador)
- Menu lateral fixo
- Seção de perfis sugeridos
- Layout em três colunas (menu, feed, sugestões)
- Botão de mensagens flutuante

## 🛠️ Tecnologias

- React
- CSS (Flexbox)
- useState (gerenciamento de estado)


## 📚 O que aprendi

- Componentização no React
- Gerenciamento de estado com useState
- CSS Flexbox para layouts complexos
- Organização de pastas em projetos React
- Separação entre dados e componentes visuais
